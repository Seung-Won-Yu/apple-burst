# 경험 구조

## 모바일

```text
QR 접속
→ 세로 시작 화면
→ 60초 도전 시작
→ 전체화면 요청
→ 6×12 게임판
→ 결과와 기기 최고점
→ 다시 하기 / 공유
```

## 데스크톱

```text
페이지 접속
→ 가로형 시작 화면
→ 모드 선택
→ 왼쪽 세로 HUD + 12×6 게임판
→ 결과
→ 다시 하기 / 공유
```

## 공통 상태

- 기본 효과음 OFF
- 오프라인 기록 저장
- 정답/실패/자동 섞기 피드백
- 마지막 5초 경고
- 신기록과 일반 종료 구분
- 가로로 돌린 모바일은 세로 전환 안내
