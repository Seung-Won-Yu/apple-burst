# 사과 팡팡 반응형 프리미엄 리디자인

## 목표

행사 QR로 처음 접속한 사용자가 설명 없이 규칙을 이해하고, 모바일과 데스크톱에서 각각 화면을 충분히 활용해 60초 게임을 완주할 수 있는 완성도 높은 웹게임을 만든다.

## 대상 사용자

- 인공지능사관학교 멘토매칭데이 현장 참여자
- QR로 처음 접속하는 모바일 사용자
- 발표 화면이나 노트북에서 시연하는 데스크톱 사용자

## 성공 기준

- 모바일 세로 화면에서 큰 사과와 전체 게임판이 한 화면에 표시된다.
- 데스크톱에서는 가로형 게임판과 세로 HUD가 자연스럽게 보인다.
- 시작 화면에서 `4 + 6 = 10` 규칙과 시작 행동이 즉시 이해된다.
- 정답, 실패, 섞기, 카운트다운, 종료가 시각·청각적으로 구분된다.
- 온라인 연결 없이도 게임과 기기 최고점 저장이 정상 동작한다.

## 범위

- 모바일 `6×12`, 데스크톱 `12×6` 반응형 게임판
- 방향별 HUD, 시작 화면, 결과 화면 최적화
- 효과음과 터치 피드백 유지
- README와 운영 설명 최신화
- 모바일·데스크톱 실플레이 QA

## 비범위

- 온라인 실시간 랭킹 재활성화
- 계정, 서버, 결제 기능
- 점수 규칙 변경
