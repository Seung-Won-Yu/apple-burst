# 사과 팡팡 반응형 프리미엄 리디자인

## 목표

QR이나 링크로 처음 접속한 사용자가 설명 없이 규칙을 이해하고, 모바일과 데스크톱에서 각각 화면을 충분히 활용해 게임을 완주할 수 있는 완성도 높은 웹게임을 만든다.

## 대상 사용자

- 짧은 시간에 바로 플레이하려는 사용자
- QR로 처음 접속하는 모바일 사용자
- 발표 화면이나 노트북에서 시연하는 데스크톱 사용자

## 성공 기준

- 모바일 세로 화면에서 큰 사과와 전체 게임판이 한 화면에 표시된다.
- 모바일 세로 화면은 브라우저 높이에 맞춰 HUD와 게임판이 함께 축소되며 페이지 스크롤을 만들지 않는다.
- 데스크톱에서는 `14×7` 가로형 게임판과 상단 HUD가 자연스럽게 보인다.
- 시작 화면에서 `4 + 6 = 10` 규칙과 시작 행동이 즉시 이해된다.
- 정답, 실패, 섞기, 카운트다운, 종료가 시각·청각적으로 구분된다.
- 온라인 연결 없이도 게임과 기기 최고점 저장이 정상 동작한다.

## 아트 디렉션

`Calm Orchard Arcade` 한 가지 언어로 통일한다.

- 따뜻한 아이보리 배경 위에 짙은 과수원 초록 프레임을 사용한다.
- 핵심 행동과 사과는 선명한 레드, 성공과 보상은 골드로 강조한다.
- 과한 체크무늬와 중첩 카드를 줄이고 게임판·사과·시작 버튼에 시선을 집중한다.
- 사과는 광택, 잎, 테두리, 바닥 그림자를 분리해 작은 화면에서도 입체적으로 보이게 한다.
- 모바일은 상단 HUD와 한 손 터치 영역을 유지하고, 데스크톱은 게임판 너비에 맞춘 가로 HUD를 사용한다.
- 데스크톱 로비는 게임판 프레임과 분리하고, 실제 게임은 사과 크기가 과도하게 커지지 않도록 최대 폭을 제한한다.
- 반복되는 배경 장식과 중첩 그림자를 제거하고, 기본 확대·흔들림을 짧고 작게 제한한다.

## 범위

- 모바일 `6×12`, 데스크톱 `14×7` 반응형 게임판과 분리된 기기 기록
- 방향별 HUD, 시작 화면, 결과 화면 최적화
- 효과음과 터치 피드백 유지

- README와 운영 설명 최신화
